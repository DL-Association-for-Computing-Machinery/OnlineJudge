# P5 个人预览代码草稿

2026-11-14，使用现有前端 Docker 工具链验证 lint、类型、143 项 Vitest、生产构建和仓库策略。可控计时覆盖 1 秒停输、连续输入 5 秒目标、旧保存回执、离页在途写入、权限失效与初读恢复；退出前切至不同账号时没有发送退出请求。

本地 HTTPS 上用既有 Chrome 与 Playwright 测试真实 IndexedDB，账号接口由测试提供合成身份及失败响应。桌面和 390 像素窄屏核对：刷新恢复、双标签副本可选、切换账号和题目隔离、主动退出默认清理及取消清理、自然过期保留、断网保存、会话请求暂时失败后恢复未保存代码、禁用存储时错误提示与下载，以及达到账号记录上限时保留当前编辑。未发送代码或调用正式提交接口。

此轮账号接口夹具不代替真实邮箱或服务端会话验收。尚未验收浏览器原生磁盘配额、数据库版本升级阻塞或真实比赛和多语言编辑流程；首期仍只支持个人预览 GNU++17。行为与回退见[前端设计](../../architecture/frontend-design.md#浏览器本地代码草稿)。
