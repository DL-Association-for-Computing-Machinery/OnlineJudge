# P7 整阶段本机验收

目标环境是 Mac 上的专用 Ubuntu arm64 VM。判题使用固定断网槽及真实 Worker，双节点用不同终端、mTLS 身份和执行槽。在临时 PostgreSQL、Redis 和回环 HTTPS 下验收，未部署、未连接试用数据。

| 范围 | 本机证据 |
| --- | --- |
| 已发布 A+B 文本题 | [C17](p7-c17.md)、[GNU++20](p7-gnu-cpp20.md)、[Java 21](p7-java21.md)、[Python 3.14](p7-python3.md)包含各自的资源边界、接管和重判；同一组合镜像回归保留 GNU++17 |
| 逐题浮点 | [十分之一极差](p7-decimal.md)通过原审核和发布门槛；八笔真实提交验证精确边界、非法输出、OLE、本人回读和账号隔离，另验双 Worker、接管和原版本重判 |
| Testlib SPJ | [数列极差](p7-testlib-spj.md)覆盖替代答案、OLE、历史重判、双 Worker、失效接管和持续判题；断网探针覆盖混合字段、诊断限额及协议 |
| 邮箱账号流程 | [P3 隔离 Gmail 真实投递记录](../delivery-log.md#2026-11-14p3-隔离-gmail-真实投递)保留用户报告；此次整阶段在临时夹具回归账号生命周期和回档，未向外部发信 |

后端格式、静态与竞态检查、PostgreSQL 集成及 API 进程检查通过。PostgreSQL 复跑含四种新增语言的迁移回退保护、权限、幂等、过期租约、恢复围栏与重判。前端静态、类型、170 个测试和生产构建通过；本机语言联验另启 Java/Python 开关。

合入主线共用前端传输后，重新构建前端并用已发布 A+B 验证 C17、GNU++17、GNU++20、Java 21、Python 3.14。15 笔浏览器回执与数据库逐笔对应到一个完成的真实 Worker 尝试；核对本人回读、其他账号拒绝、错版本、刷新后读原键及同键冲突。数据库对账 SHA-256 `f207670583384b9e5ed25db8bae40b684311abfe2a22ceeeba6b3e048c808e9b`。

普通会话、邮件生命周期及邮件回档三组竞态专项最终全部通过，含真实数据库回档后旧 Cookie 拒绝。运行容器只连接一次性 PostgreSQL、Redis 和回环 SMTP；已有 Gmail 实收记录继续单独列证。
