# Web 界面与预览边界

用户于 2026-11-01 确认简洁的专业刷题界面，当前优先桌面 Web。首页、登录页和做题页视觉稿已确认；本次替换静态界面，不扩大公开题库、生产提交或注册的交付范围。

后续界面维护遵循根目录 [设计约定](../DESIGN.md)。

## 页面与交互

| 路径 | 当前行为 |
| --- | --- |
| `/` | 示例题库，题号/名称搜索、折叠难度和标签筛选、每页六题；条件保存在 URL |
| `/login` | 独立窄表单；沿用真实同源 HTTPS 登录与原候选恢复流程 |
| `/account` | 当前会话、显式续期/退出、可选改密；连接诊断折叠，旧 `/#account-title` 转到此页 |
| `/preview/problems/:id` | 本地合成题面、CodeMirror C++ 编辑、键盘/拖动分栏、文件导入和下载；提交禁用 |
| `/submissions` | 明确提示正式提交记录尚未开放 |

首页不放统计卡片、侧栏或营销区域。白底、深色正文、克制的橙色操作色，系统字体不请求外部字体。按钮、输入框、导航和表格共用 CSS 变量及可见键盘焦点；只有 150ms 状态过渡和 160ms 折叠内容淡入，遵守 `prefers-reduced-motion`。参考 [shadcn/ui](https://github.com/shadcn-ui/ui) 的基础控件层次与 [Radix 动画指南](https://www.radix-ui.com/primitives/docs/guides/animation)，没有复制其实现或新增动画依赖；Tailwind/shadcn 的后续技术路线不因此改变。当前保留窄窗口基本可用性回归，不代表新的移动端设计已验收。

## 生命周期与依赖

React Router 声明式路由负责导航，账号 controller 提升到应用生命周期，站内链接不重建它；改密未知标记因此能跨首页/预览/账号导航保留。完整刷新仍会清除该内存标记，边界见[浏览器账号](account-browser.md)。首个会话检查或身份未知时不挂载编辑器，避免用户输入后被身份空间切换清除。

示例代码只存在当前标签页内存，站内导航按题号保留；观察到身份空间变化时清除，刷新/关闭提示下载。上传只接受不超过 128 KiB 的 UTF-8 `.cpp/.cc/.cxx/.txt`，拒绝 NUL/无效 UTF-8；未编辑的导入文本下载保留原始 Unicode 和换行。异步文件读取在卸载或编辑版本变化后不能覆盖新输入。示例功能不向 API 发送代码，不把内存暂存声称为 AC21 的 IndexedDB 持久草稿。

精确版本归 [package.json](../web/package.json) 与锁文件：React Router 8.5.1、CodeMirror 6.0.2、C++ 扩展 6.0.3、state 6.7.6、view 6.43.15，均 MIT。Router 的 Node 下限为 22.22，项目支持 `^22.22.0 || ^24.0.0`，Docker 固定 Node 24.19.0。编辑器按路由懒加载，避免首页/登录首屏下载；未引入 Query、持久草稿或 Markdown 渲染依赖。

## 验证与回退

执行 README 中 Docker 前端检查及[浏览器账号专项](../README.md#浏览器账号专项)。浏览器专项保留原账号断言，并检查跨页改密保护、编辑前身份检查、迟到上传隔离、原文下载、站内保留、全局离开提醒、搜索/筛选/分页、减少动画及示例零 POST。正常账号流程使用隔离的真实 HTTPS/race API/PostgreSQL/Redis；故障回执为定向注入。

默认 Compose 仍为 HTTP/bootstrap，登录表单禁用；本机预览不代表生产账号入口或判题已上线。没有数据库迁移，回退前端构建即可恢复原界面；后端会话持久状态不随静态资源回退撤销。生产 HTTPS、注册、正式题库/提交、IndexedDB 草稿及完整 M0 另行交付。
