# 本地不可变材料存储

`internal/materialstore` 实现[存储设计](architecture/storage-design.md#4-文件发布与一致性)的首个 Linux 本地适配器。它保存私有原始字节，成功完成后才可由业务事务提交引用；模块本身不承担用户授权，[上层私有草稿服务](problem-drafts.md#私有草稿入库与本人读取)已接通授权与数据库引用，审核和发布仍待实现。服务只依赖`Store`的`Put/Open`及`Object{SHA256,Size}`，不依赖供应商URL或用户可控路径。命令归[README](../README.md#本地不可变材料存储)。

## 根目录、预算与生命周期

维护者必须先在可信祖先下预建专用持久根，并完成根及父目录的持久化准备。根须为普通目录、当前进程euid所有、精确0700；`OpenLocal`固定目录描述符，拒绝最终根符号链接，不创建、修复或清理根。Linux文件系统必须支持文件和目录`Sync`；不能把此合同外推到NFS、Docker Desktop宿主共享挂载或对象存储的断电语义。

`Config`显式给定`MaxObjectBytes`与`MaxInFlight`，分别允许1字节—1TiB、1—64个活动操作；实现上界不是生产建议。CLI每进程只开1槽。每个Put临时副本或Open快照受每对象预算约束；快照保持槽位直到Close，满额立即`ErrBusy`，不无限排队。多实例额度相加；已提交对象、崩溃遗留文件、磁盘总容量及保留期不由该计数控制，生产共享配额和两阶段清理仍待后续实现。

`Local.Close`在活动操作或快照存在时返回`ErrBusy`，调用者排空后重试；正常关闭与快照关闭均幂等。上下文只在读写/同步边界合作检查，不能强行中断任意Reader、磁盘I/O或Sync；Put只接收可信、有自身阻塞界限的Reader，不直接作为任意上传服务。根目录及同UID维护进程属于信任边界，0600不阻止同UID程序改写文件。

## 不覆盖发布与未知回执

1. 校验64位小写SHA-256、声明长度与预算；逻辑标识不能表示路径。独占创建同目录`.pending-<随机值>`，通过自身描述符设置0600，避免严格umask导致成功对象不可读。
2. 最多读取声明长度＋1字节，流式写入并核对实际长度和哈希；不匹配、取消或写入失败不能发布最终名称。完整文件Sync并关闭后再提交。
3. `Root.Link(临时名称,哈希)`原子创建最终名称，绝不覆盖。若已存在，以`NOFOLLOW/NONBLOCK`打开，检查普通文件、owner、精确0600、长度及全部哈希，再单独Sync；存在不等于已获持久化确认。损坏或异主对象拒绝，不自动修复。
4. 删除本次临时名称并Sync根目录后才返回成功。Link后取消仍完成持久化收尾；后续失败为`ErrCommitUnknown`，不因失败撤销最终对象。其他写入者正常发布期间可能短暂存在两个硬链接，因此不拒绝所有`nlink>1`。

Link返回错误时也保留结果可能已发生的语义。调用方按原hash/size和原内容重试Put；只在成功回执后提交数据库引用。CLI写入后的输出失败同样为未知；不能根据失败或一次不存在查询推定回滚，也不能靠生成新标识绕过核验。CLI的verify是只读完整性检查，不能确认先前失败Put的持久化；其输出错误不冒充新的写入尝试。

## 读取与恢复边界

Open先安全打开最终对象，再复制到立即unlink的私有磁盘快照，完整验证长度/哈希后才返回可读句柄；不会校验后直接返回仍可能被改动的原inode。已验证快照不受随后原文件修改影响，取消后读取失败，Close释放槽位及匿名文件。错误分类包含非法请求、不存在、完整性、不可用、忙和已关闭；业务服务仍须先执行授权并映射对外响应，猜中哈希不授予读取权。

进程崩溃可能留下`.pending-*`，不会被逻辑对象读取。实现不自动清理这些文件；后续维护必须协调活跃写入、引用与保留期，不能仅按文件年龄删除。根路径名称的祖先和文件系统挂载由运维保护；本模块不是针对同UID恶意修改者的隔离边界。

## 已验证范围与后续

Docker Desktop LinuxKit7.0.14/arm64的专用ext4命名卷上，已逐对象导入Library Checker十题bundle的**597个去重对象、1,460,825,722字节**；新容器不挂载来源目录，重新打开并完整校验全部对象，权限/数量/大小回读一致。原始bundle和临时工作目录不作为独立备份，专用验证卷保留供复核。

普通root race覆盖双实例/双独立进程竞争、幂等不换inode、完整快照、预算、取消、特殊文件/链接/权限拒绝、文件/目录Sync及回执失败注入、五个进程中断阶段、严格0777 umask。owner专项在独立root夹具中核验，真实写满专项仅填充独占512KiB tmpfs，观察ENOSPC、无最终对象与同实例后续恢复；普通CI明确跳过这两个显式专项，分别手动通过。精确命令、源文件与日志哈希见[机器证据](evidence/material-store-20261103.json)。

这些证据不验收真实持久磁盘断电、全盘容量、跨主机共享、孤儿回收、独立备份或业务题目发布。P4私有草稿服务已在完整保存材料后同事务检查当前出题权限并提交数据库固定引用；加入题面/草稿/证据后的622对象联调归草稿合同，不改写本页原597对象证据。受限验证、审核及发布继续待交付；当前M0材料入口保持原有独立实现及门禁。
