# A+B 目标节点交接演练

在本机使用[目标节点交接命令](../checker-admission.md#ab-目标节点交接)打包固定 A+B 17 点材料，节点标签为 `local-rehearsal`，请求绑定主线候选 `4184ed4c01297704f702b349c1f4b2e7cb7f4a35`。目录包含 32 个摘要对象及两份清单；相同参数的两次导出逐字节一致，交接清单摘要 `ef36b6a9d5b06369448910972fa32acc6a25b32b839bd77e384540bb85484d85`。接收副本核验通过，错节点、缺文件、多余文件及破坏对象的副本均拒绝且没有输出回执。

使用同机现有固定断网参考槽重跑三个合成对照，各得到 AC、WA、OLE；每轮停止后，同一槽为 `exited`、PID 0、网络模式 `none`。三份新报告通过 `reports` 回读，交换新 AC 和 WA 报告、提交旧三份归档均拒绝。报告只证明固定本机档位的内容回读；请求中的候选 SHA 和节点标签不是构建或主机身份认证。未连接试用服务器，未验证现场档位、正式检查器准入或发布。
