# P7 Testlib 协议与隔离验收

首个验证基线为 [Testlib 0.9.45 固定提交](https://github.com/MikeMirzayanov/testlib/blob/2d20123984e9479b8a56ebe0d6a51e23ad7c35b3/testlib.h)。已有题源语料内的 0.9.40 快照仅用于既有文本比较对照。

本站区分原生 ICPC 与下游 Testlib 协议。两者均须接收限额内真实的进程正常退出；信号、超时、资源超限、文件采集错误和缺失回执均为检查器系统错误。原生 ICPC 的 42/43 与下游 Testlib 的 50/51–54 分开解释，退出 0 和未知码拒绝。诊断只用于排查，不参与结果映射。

[头文件准备脚本](../../scripts/prepare-testlib-spj.py)校验独立 SHA-256 及固定上游 Git blob，保留许可，标记修改。下游适配在额外输出检查之前把评分关闭：上游的部分分退出码可按参数计算，且可能先因额外输出被折成格式错误；单独调整基础退出码不足以隔开这些情况。只有适配过的版本和固定编译参数可配合本站解码器。

本机从上游固定提交取得头文件，Git blob 为 `349b839ff14e3b933668e9938dbbe04ecb265843`，原始 SHA-256 为 `bb323e3c89285214966076e0d23d5a295c5f6126da7ff198c1276ddb95ecb1a0`，适配后为 `529f92008bc444628ac657da3e5245ebf2bbfdf37c24a88d80114dec14728015`。在断网 VM 用固定 GCC 15.3.0 的 GNU++17 编译；协议探针 12 项通过，含两种合法答案、错值、畸形、额外输出、选手 EOF、输入/答案错误及带额外输出的部分分。测试输入、选手输出和参考答案只送给检查器；诊断预算独立。

复现探针时在专用 Ubuntu arm64 VM 中创建专用停止容器，沿用 [Python 组合镜像和 Ubuntu 槽](p7-python3.md)的断网、只读、无挂载及资源配置，所有者标签使用 `owner=onlinejudge.p7-testlib-probe`。启动后，以 VM 管理用户执行 `python3 -B scripts/probe-testlib-spj.py CONTAINER_ID ORIGINAL_HEADER EXPECTED_SHA256`。仅转移该脚本、准备脚本及本页的两个合成检查器到 VM；结束后确认专用容器停止并释放。此探针不接收任意检查器源码，不进入正式发布队列。

发布试点使用 `build-span-fixture.py ... --spj` 生成的数列极差题包。现有参考、独立算法对照、覆盖、授权渲染和审核仍是门槛。另用探针的 `--span-bundle`、`--output`、`--plan-sha256`、`--runtime-sha256` 选项对每个正式点检查标准输出、合法替代输出及错误输出。正式计划摘要取自同一冻结库的正式报告；运行摘要用 `checker-candidate local-spj-runtime-pin` 读取。确认探针停止后，向 `export-local-text` 追加 `--spj-report` 和 `--expected-spj-report`，沿现有流程注册、审核、发布。报告绑定源码、头文件、镜像、完整计划、运行契约和实际检查器制品；声明检查器却不配置通过的报告会被拒绝。

训练 Worker 用已核验的组合镜像（`OJ_LOCAL_PYTHON3=1` 选择该镜像），另以 `OJ_LOCAL_SPJ_CHECKER_FILE` 提供已固定的私有制品。每点最多三份 256 KiB 材料，最多 16 点；检查器限 CPU 1 秒、墙钟 4 秒、内存 128 MiB、进程 8，每个诊断流 4 KiB。检查器与选手使用分开的缓存账本和每次运行的新进程；检查器制品及答案不会出现在选手的运行请求里。

## 数列极差发布与真实 Worker

2026-11-15，断网 Ubuntu arm64 VM 对 13 个正式点执行 39 次检查器对照；标准、合法替代输出均通过，各点错值被拒。实测不带 SPJ 报告时无法导出执行清单。作者真实提交参考验证，独立 mTLS 参考 Worker 回报全部 AC，随后作者确认标程、非作者完成题意确认及审核，另一个发布账号在临时库发布 `676e5b26c7c30ef7084479027d5b06d6077c650593b3279a040827d6ed783810`。

Chrome 普通账号提交标准答案、双整数替代答案和空输出，真实训练 Worker 判为 AC、AC、WA。本人可读结果及原始源码；另一普通账号不可读取，错误发布版本拒绝。数据库逐笔对账三份浏览器回执，每份只有一次完成的真实 Worker 尝试。SPJ 报告 SHA-256 `475b4d0e03c6651a68a1b79cd2c6d845e126d5f5c8902a46eb36c787b4a04223`，浏览器报告 `5c53413478e1114a0d374389ea3b8ca7df7de5fff5f82f9634741a6665563560`，最终数据库对账 `91775cbd8ed915686490d4ea48c04ffe8df4afd7567d821ca3804535bc640c18`。专用 Worker、沙箱及临时夹具均停止。

这轮验证单题单 Worker；SPJ 历史重判、双 Worker、真实检查器异常及浮点题仍须验收。额外的超长选手输出探查没有完成 OLE 验收：普通文本的 token 限额不适用于 SPJ，超过传输字节上限的用例还需单独复核执行器回执和映射。未部署，未连接试用数据。
