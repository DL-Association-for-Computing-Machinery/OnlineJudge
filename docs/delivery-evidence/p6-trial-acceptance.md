# P6 整阶段验收清单

本页对应[开发计划 P6](../phase-1-development-plan.md#p6-试用运行与验收)。剩余变更集中在 [#296](https://github.com/DL-Association-for-Computing-Machinery/OnlineJudge/pull/296)，按功能原子提交。已合入的本地演练继续作为分项证据；只有下列整阶段条件均有证据、最终 CI 和审查通过后，才结束草稿。

| 完成条件 | 已有证据 | 待完成 |
| --- | --- | --- |
| 同源 HTTPS、健康和就绪、值守可见性 | 本地冷 HTTPS；进程存活；草稿中的[普通会话就绪与判题快照](../architecture/operations-design.md#2-可观测性) | 在试用配置验证代理、CA、校内 DNS 和断外网；核对实际节点可用性、结构化日志及故障处理入口。配置槽数不代表在线容量。 |
| 集中登录、混合训练、过载恢复 | 隔离浏览器集中登录和队列积压恢复分项 | 实际同源 HTTPS 与试用预算下补测；混合训练和过载各至少三轮，记录计划规定的时延、失败、队列、资源峰值和恢复。依赖 P4 已审核题目材料与 P5 提交闭环。 |
| 独立备份和恢复 | 合成备份、恢复后重判，以及旧会话、租约和恢复代次的分项证据；[恢复证据核对](../architecture/operations-design.md#试用恢复计时与证据)绑定五份观察记录 | 落实独立设备或存储介质、访问权限及值守人；源主机不可用时验证 RPO、RTO、历史读回、旧凭据拒绝与重判。 |
| 现场发布排空、迁移、健康检查和兼容回退 | #293 验证同库 schema 20→25→20，保留既有结果并处理新版排队提交；实验判题已做离线包冷接收；[应用制品](../../README.md#试用离线应用制品)可一次导出 Linux 程序和正式前端 | 固定实际拓扑、运行镜像、模板和环境；完整离线包、冷接收和正常回退分别验收。现场执行仍需发布授权。 |
| 缓存/临时文件容量及占用保护 | 受限运行与材料专项提供分项证据；[只读预检](../../README.md#试用服务器只读盘点)可按已登记的字节和 inode 峰值核对共享卷余量 | 在试用拓扑核对底层存储池及配额，实测峰值和清理前后的剩余空间；不得自动销毁保留期未定的核心记录，不删除正在使用的材料或恢复引用。 |
| 跨实例与运维文档 | 已有普通会话双 API 和隔离协议专项 | 核对目标配置与多实例约束，落地试用拓扑、配置、备份、回退和故障说明；不把本地实验当公网或生产证据。 |

阈值以[试用容量和恢复默认值](../phase-1-development-plan.md#试用容量和恢复默认值)为准。现场授权、独立故障域或依赖阶段未就绪时，记录缺口并保留同一草稿。
