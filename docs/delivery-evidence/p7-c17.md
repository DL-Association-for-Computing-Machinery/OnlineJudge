# P7 C17 本机验收

已发布的本机文本题可在浏览器选择 GNU++17 或 C17，分别保存草稿；C17 接受单个 UTF-8 `.c` 文件。旧客户端省略语言时仍使用 GNU++17。语言随源码纳入收件指纹：同一请求键换语言返回 409，恢复原键仍读回同一结果。M0 合成入口仍只接收 GNU++17。

P4 参考验题和已发布材料的摘要仍绑定原 GNU++17 参考档位。提交语言由租约对应的数据库记录读出，Worker 用固定代码把 C17 映射到 GCC 15.3.0、`-std=c17 -pedantic-errors` 和 `main.c`，使用原隔离槽、预算、检查器及冻结测试数据。后续修改这个编译配置需要新的版本，不能悄悄改变历史 C17 的执行定义。

schema 30 只扩展提交语言约束。迁移前排空并停止旧 API、Worker 和维护写入，再以同一修订启动；旧 Worker 能领取同一材料队列，但不能处理 C17，禁止混跑。Down30 只在没有 C17 记录时才允许恢复旧约束；有 C17 历史时迁移拒绝回退，保留原数据。保留数据并向前修复。
